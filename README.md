# Hola, soy Luis Ortúzar

**Ingeniero en Informática · Full Stack Developer** · Santiago, Chile 🇨🇱

Desarrollo y mantengo plataformas CRM para call centers que atienden a clientes de banca, seguros y medios de pago. Trabajo de punta a punta: base de datos, backend, reportería, telefonía y automatización.

### 🛠️ Lo que hago en el día a día
- **Backend y bases de datos:** funciones en PL/pgSQL, modelado y optimización en PostgreSQL
- **Reportería:** reportes en JasperReports (JRXML) conectados a PostgreSQL
- **Web:** formularios y UI en PHP, JavaScript, HTML y CSS
- **Telefonía:** configuración de Asterisk / ViciDial y procesamiento de CDR
- **Automatización:** pipelines de datos con bash, FTPS y tareas programadas; flujos en n8n

### 📚 Aprendiendo ahora
- Node.js + React + TypeScript
- Java + Spring Boot
- AWS (preparando Cloud Practitioner)
